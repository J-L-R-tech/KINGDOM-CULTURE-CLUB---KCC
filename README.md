# The Kingdom Culture Club — Official Website Repository

**Subject Code:** WEDE5020  
**Module Name:** Web Development 5020  
**Project Description:** A fully responsive, functional, and SEO-optimized 5-page web platform for *The Kingdom Culture Club*, a community organisation uniting car culture, youth mentorship, and faith-based community values.

---

## Part 3 Enhancements & Features

- **JavaScript Functionality:** Added dynamic content handling, real-time search filtering on project/service listings, and client-side form validation with user feedback prompts.
- **On-Page & Off-Page SEO:** Implemented descriptive meta titles, meta descriptions, keyword optimization, alt attributes on all images, and semantic HTML5 heading structures.
- **Search Engine Directives:** Created a custom `robots.txt` configuration and XML `sitemap.xml` to assist web crawlers.
- **Deployment:** Successfully deployed and hosted live on a cloud platform (Netlify / GitHub Pages).
